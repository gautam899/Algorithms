# Minimum Spanning Tree

- Minimum Spanning tree is subset of the edges of the connected edge-weighted undirected graph that connect all the vertices of the graph without forming a Cycle.

- Application: In telecommunication, when the cables are to be burried under the roads(edges) and connect all the houses(vertices) to keep the cost of the operation as low as possible, MST is used. The cost per road is the edge-weight in this case.
